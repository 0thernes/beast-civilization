# Support (`A17`)

- **Bug Reports, Counterexamples & Feature Requests:** Open an issue using the structured templates in [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/).
- **Replication & Verification Help:** Follow [`REPLICATION.md`](REPLICATION.md) and [`docs/faq.md`](docs/faq.md) first; include OS, CPU/GPU, toolchain versions (`zig version`, `rustc --version`, `lean --version`, `ruby --version`), and full command output in any report.
- **Security Vulnerabilities:** Follow [`SECURITY.md`](SECURITY.md) — do not open public issues for unpatched Ring-0 isolation, SSRF, or parser safety vulnerabilities.
