# Code of Conduct (`A15`)

This project adopts the Contributor Covenant Code of Conduct (v2.1) principles for open scientific collaboration:

- **Scientific Rigor & Honesty:** Critique ideas, proofs, code, and measurements directly and constructively; never attack contributors personally.
- **Welcoming Environment:** Respect all researchers, reviewers, and users regardless of background or affiliation.
- **Transparency:** Report bugs, errors, counterexamples, and replication discrepancies openly via GitHub Issues or direct maintainer contact (`0_0@0thernes.art`).
- **Enforcement:** The project maintainer (Alexander Stephen Donahue, `0_0@0thernes.art`) reviews all conduct concerns promptly and fairly.
